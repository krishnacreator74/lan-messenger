# LAN Messenger - Client

This is the frontend of the LAN Messenger application built using React.

## Setup

```
npm install
npm start
```

## Features

* Login / Signup UI
* Chat rooms interface
* Real-time messaging (Socket.IO)
* Audio message support

## Environment Variables

Create a `.env` file:

```
REACT_APP_API=http://localhost:5000
```

## Tech Stack

* React.js
* Socket.IO Client
* CSS

## Notes

* Make sure backend is running before starting the client
